# Notebooks

These are sanitized exports of the notebooks executed for the completed academic project:

1. `01_data_cleaning_and_feature_engineering.ipynb`
2. `02_date_quality_validation.ipynb`
3. `03_exploratory_data_analysis.ipynb`
4. `04_offers_model_evaluation.ipynb`
5. `05_award_value_model_training_and_evaluation.ipynb`

The notebooks document the original GCP Dataproc and GCS workflow. Large datasets, feature vectors, trained Spark models, and cloud credentials are intentionally excluded.

Spark-monitor progress payloads and empty placeholder cells were removed for readable GitHub rendering. Meaningful executed outputs, model metrics, tables, and charts were retained. One malformed exploratory date-summary cell was corrected during sanitization and deliberately left unexecuted; its previously failed output was not presented as evidence.
