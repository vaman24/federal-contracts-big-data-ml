# Notebooks

The final portfolio should contain numbered, restartable notebooks:

1. `01_data_audit.ipynb`
2. `02_cleaning.ipynb`
3. `03_exploratory_analysis.ipynb`
4. `04_feature_engineering.ipynb`
5. `05_model_training.ipynb`
6. `06_evaluation.ipynb`

Each notebook should read from a documented GCS stage, write to a new stage when appropriate, and avoid depending on hidden in-memory state from a previous notebook.
